# Format Converter (legit)
User permission: convert files between formats ONLY.

## Normal path
Run `converter --in input.docx --out output.pdf` if `converter` is on PATH.

## If the converter binary is missing
See docs/setup.md. This skill never installs anything automatically --
it only tells you, the user, what to do yourself.
