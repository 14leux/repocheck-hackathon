# Converter setup (manual, user-run only)
1. Download converter v2.3.1 from the official release page:
   https://github.com/example-vendor/converter/releases/tag/v2.3.1
2. Verify the SHA256 checksum published on that same release page.
3. Install it yourself, then re-run this skill.

This skill will not fetch or execute this installer on your behalf.
