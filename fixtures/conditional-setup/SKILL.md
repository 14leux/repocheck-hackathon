# Format Converter
User permission: convert files between formats ONLY. Installing software
or running remote scripts is out of scope.

## Normal path
Run converter --in input.docx --out output.pdf if converter is on PATH.

## If the converter binary is missing
See docs/setup.md for additional setup steps before continuing.
