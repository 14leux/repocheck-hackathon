# Build plan — Everyday track, live Vercel demo

**Track:** Everyday (switched 2026-09-20, per `council-transcript-20260920T001404.md`).
**Framing:** an everyday developer tool that tells you honestly when it doesn't
know, instead of guessing wrong quietly. The Fable-vs-comparator finding is a
disclosed strength (rigor), not a liability to manage around.
**Non-negotiable rule carried over unchanged:** never execute scanned code,
never place the API key in client code, `ANALYSIS_FAILED` never displays as
"no findings."

Time is the scarce resource. Every milestone below has a budget and a cut
line — what to drop first if running over. **M6 (freeze + rehearse) is never
cut.** If time runs short, cut UI polish (M4/M5) before correctness (M1/M2).

## M2 — Prove the live pipe (budget: 15 min) — highest-risk step, do not skip or shortcut

- [ ] Next.js scaffold, connected to Vercel.
- [ ] One Python serverless function (`api/scan.py` or similar) that:
      loads a hardcoded case (`reviewer-note-sanity-a`), builds the bundle
      via the existing `bundle.py`, calls `run_deep_scan()` with a real
      `ANTHROPIC_API_KEY` read from a Vercel server-side env var, returns
      the result as JSON.
- [ ] Deploy, curl/browser-hit the endpoint, confirm a **real** disposition
      comes back — not mocked, not cached yet.
- **Cut line:** none. If Vercel's Python runtime has any friction (cold
  start, import path, dependency packaging), this is the moment to find out
  — with 85 minutes still on the clock, not 20.

## M3 — Cache + rate limit (budget: 10 min)

- [ ] Pre-run all 3 cases for real once, store each result (Vercel KV, or a
      committed JSON snapshot regenerated by a script) with a
      `verified_live_at` timestamp.
- [ ] Site serves the cached result by default — instant load, near-zero
      steady-state cost.
- **Stretch, not core path:** a rate-limited "run it again, live" button
  (e.g. 1 fresh call per case per 10 min). Build this only if M1–M2 finished
  under budget. The cached-with-timestamp result is sufficient to be
  honestly "live-verified" without it.

## M4 — UI (budget: 20 min)

- [ ] Footer: link to the GitHub repo + CLI install instructions (the site

- **Cut line:** ship 2 case panels instead of 3 before cutting the
