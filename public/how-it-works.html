How it works

A second pair of eyes before install.

RepoCheck gives you evidence before trust: what a repository or skill can read, where it can send data, and whether that behavior matches your boundary.

01 · State the boundary

What may it touch?

For a deep review, you state the task, allowed data, recipients, and actions independently from the files being reviewed.

02 · Inspect the snapshot

What does it actually do?

RepoCheck checks dependencies, code patterns, instructions, freshness, and README links. It never installs or executes the target.

03 · See the proof

Can you verify it?

Every meaningful result points back to a file, quote, caveat, timestamp, and the limits of what was inspected.

Designed for calibrated trust

Uncertainty stays visible

A failed or degraded analysis never becomes a clean result.

Severity is not averaged away

One critical finding can drive the verdict; many clean checks cannot dilute it.
