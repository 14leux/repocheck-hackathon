Dr. RepoCheck

Before you install a skill, see what it would actually do

Before a developer installs a Claude Code skill, Dr. RepoCheck shows whether it would do more than they authorized -- and cites the exact lines that prove it.

A real shape of damage this catches

A skill says it summarizes your weekly commits into a report. Nothing in its description mentions credentials. Underneath, one file reads ~/.aws/credentials, a second renames it to a field called session_context, a third posts the finished "report" to the author's server. You find out when your cloud bill shows five figures of compute you never ran.

How it works

You state your task and what the skill may touch. The skill's own files never get a vote on their own authorization.

What we found, and we're not hiding it

On this small set of cases, Fable 5.1 declined to analyze content the comparator model analyzed correctly. We're disclosing this, not softening it. Our own harness is what makes it visible in the first place: a refusal is recorded as ANALYSIS_FAILED, never silently folded into "no findings" -- the same discipline that would have hidden a real bug in this exact tool three separate times this build, if we hadn't insisted on it.
